Core experience

Ikke bare en wrapper.
Et helt lag ovenpå.

NSX kombinerer det originale chatmiljø med værktøjer, realtime-status og automation i samme klient.

01 / CORE

Integreret Netstationen

Netstationen åbnes direkte i NSX via WebView2, så chatten føles som en del af selve desktop-klienten.

  • Ingen separat browser nødvendig
  • NSX-funktioner tæt på chatmiljøet
  • Direkte genindlæsning og chat-start
02 / LIVE

Dashboard & live-status

Ét samlet overblik over klient, server, licens, runtime, session og automation.

03 / AUTO

Automation

Auto Login, Auto Logout, Auto Chat, rum-workflows, Bingo Assistent og andre tidsbesparende værktøjer.

04 / CHAT

NSX Chat

Privat chat med rum, direkte beskeder, unread-state, typing-status, roller og moderation.

05 / BRIDGE

Telegram Bridge

Ekstern kontrol og notifikationer via Telegram-bot, inklusive tekst, rumoversigt og log-funktioner.

06 / OWNER

Owner & administration

Administrér brugere, roller, licenser, device-binding og adgang fra samme system. Centrale rettigheder håndhæves server-side.

  • Opret og administrér brugere
  • Forlæng, revoke eller genaktivér licenser
  • Reset device og følg administrative handlinger
07 / LOGS

Logs & realtime

Persistent WebSocket-log, chatlog, debugstatus og live Telegram-log giver indsigt i, hvad der sker.

Access control

Adgang i flere lag.

Klientlicens, chatadgang og brugerroller kan styres separat.

ServerlicensBestemmer om NSX-klienten kan låses op.
Device-bindingLicensen kan bindes ved første aktivering og resettes administrativt.
IPv4-whitelistNSX Chat kan begrænses til godkendte offentlige IPv4-adresser.
Server-side rollerOwner, Admin, Moderator og User kan have forskellige rettigheder.
